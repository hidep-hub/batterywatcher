# BW-001 タスクトレイ・バッテリー表示アプリ 調査・設計提案

- 作成日: 2026-08-10
- 対象タスク: BW-001（調査タスクとして完了）
- 目的: タスクトレイの常駐アイコン自体の中に、バッテリー残量（%）を常時数字表示するWindowsアプリを作る

## 要件（ヒデさんの元発言より）

- 世の中にあるツールは色やバーグラフばかりで、%を見るにはホバーのツールチップや右クリックが必要
- そうではなく、アイコンの中に「99」のように常時数字が見えていてほしい
- デスクトップウィジェットではなく、タスクトレイに常駐させたい
- カスタマイズ可能にしたい

## 01. 現状調査

### 世の中の実装パターン

既存のバッテリー系トレイアプリは、だいたい次の4パターンに分かれる。数字を常時アイコンの中に出す、というド直球をやっているものは少数派。

| パターン | 内容 |
|---|---|
| A. バーグラフ型 | 残量を棒の高さ/塗りで表現、数字なし |
| B. 色変化型 | 緑→黄→赤のアイコン色だけで判断させる |
| C. ホバー/クリック依存型 | 常時は非表示、ツールチップか右クリックで確認 |
| D. デスクトップウィジェット型 | トレイではなく画面上に浮かせる |

### Windows 11 標準機能の限界

Windows 11の25H2以降では「設定 > システム > 電源とバッテリー」に「バッテリーのパーセンテージを表示する」というオプションが追加されている。ただしこれはバッテリーアイコンの**横にテキストラベルが並ぶ**だけで、アイコンと数字が一体化しているわけではない。

- 通知領域が狭くなると、オーバーフロー（隠れる矢印の中）に押し込まれて消えることがある
- フォント・色・表示形式（%か残り時間か）のカスタマイズは一切できない
- Windows 11 25H2未満（企業PCだとまだ多い）では使えない

### 近い思想を持つOSSプロジェクト

「アイコンの中に%」というコンセプト自体は、実は複数のOSSが既にやっていた。ただ、どれも一長一短でカスタマイズ性は弱い。

| プロジェクト | 言語/技術 | 特徴 | カスタマイズ性 |
|---|---|---|---|
| [soleon/Percentage](https://github.com/soleon/Percentage)（Microsoft Store公開） | .NET / C# | 充電状態・健康度まで表示。Windows 11専用 | 低（通知しきい値のみ） |
| [myfix16/BatteryTracker](https://github.com/myfix16/BatteryTracker) | .NET 7 + WinUI | テーマ連動で自動配色、通知しきい値を細かく設定可 | 中 |
| shiqimei/PercentageBatteryIcon | .NET / C# | Windows 10向けの軽量実装 | 低 |
| justinnas/StarTray-Battery | .NET / C# | シンプルさ重視、依存少なめ | 低 |

## 02. 差別化ポイント

「アイコン内%常時表示」自体はニッチだが前例がある。見つけた4つはどれもカスタマイズ性が弱い（通知しきい値くらい）。「カスタマイズも可能なのが理想」を本気でやっているものはなかった。ここが自作の意味になる。

- **表示形式の切替**：%表示 ⇄ 残り時間表示 ⇄ 自動トグル、をユーザーが選べる
- **閾値も配色も自由**：何%で色を変えるか、色そのものも変更可能に
- （MCP連携は今回のスコープ外。将来検討の余地はあるが、常駐アプリ本体とは別レイヤーの話）

## 03. 技術選定

既存OSSが軒並み.NET/C#に寄っているのは偶然ではない。Windowsのトレイアイコンを動的なビットマップとして自由に描き替える仕組みが、.NETだと一番素直に書ける。

| 候補 | アイコン動的描画 | 配布のしやすさ | 設定UIの作りやすさ | 判定 |
|---|---|---|---|---|
| .NET 8 WinForms + NotifyIcon | GDI+ DrawStringで一直線 | self-contained単一exe化可 | Formsで即座に作れる | **推し** |
| .NET 8 WPF/WinUI 3 | 可能だがNotifyIcon非標準（サードパーティ必須） | Windows App SDK依存が付く | リッチだが重い | 見送り |
| Rust + tray-icon crate | 可能、ただしGDI相当を手組み | 単一バイナリで最軽量 | 設定UI用に別クレートが必要 | 見送り |
| Python + pystray + psutil | Pillowで画像生成、実装は簡単 | PyInstaller化が地味に手間 | Tkinter等が必要で見劣り | 見送り |

**採用: .NET 8 + WinForms + NotifyIcon。**

バッテリー情報は Win32 の `GetSystemPowerStatus`（または WinRT の `Windows.System.Power.PowerManager`）で%・残り時間・充電中判定まで一発で取れる。GDI+の`Graphics.DrawString`でビットマップに数字を焼き込んで`NotifyIcon.Icon`に差し替えるだけなので実装がまっすぐ。Native AOTでビルドすれば.NETランタイム未導入PCでも単一exeで動く。社内配布事情（インストーラ不要で配りたい）にも合う。

## 04. 設計

### 更新の流れ

```
電源状態取得 → 表示値を算出 → ビットマップ描画 → トレイアイコン更新
(GetSystemPowerStatus +      (%/残り時間、    (GDI+で背景色＋   (NotifyIcon.Icon
 PowerModeChangedイベント)    しきい値で色を決定) 数字をDrawString) を差し替え)
```

更新頻度は基本ポーリング30秒〜1分＋`SystemEvents.PowerModeChanged`（充電⇄放電の切り替わりを即時検知）の併用。バッテリーAPIは変化検知イベントの粒度が粗いので、ポーリングを完全には外せない。

### 最大の技術的チャレンジ：小さいアイコンに数字を収める

既存ツールがバー/色止まりだった理由はおそらくここ。通知領域アイコンは16×16px相当（高DPI環境では最大32×32）しかなく、3桁の数字を綺麗に見せるのは難しい。対策:

- 2桁固定・太字・背景色でコントラスト確保（例: 緑地に白抜き「99」）
- 1桁は中央寄せで潰れないように調整
- 数字は白抜き＋縁取り（アウトライン）でどの背景色でも視認性を落とさない
- 100%だけ3桁になる問題は、フォントサイズを1段階だけ自動縮小して回避
- 残り時間表示モードは「2h40」のような短縮表記

## 05. カスタマイズ項目（設定画面案）

| 項目 | 内容 |
|---|---|
| 表示形式 | % / 残り時間 / 自動交互切替 |
| 配色しきい値 | 危険・注意・良好の%境界を自由設定 |
| 配色そのもの | 各しきい値の背景色・文字色を変更可 |
| 充電中表示 | ⚡マーク重ね／背景色を専用色に切替 |
| フォント太さ | 視認性優先の太字 or 控えめな標準 |
| クリック動作 | 左クリックでWindows電源設定を開く等を割当 |
| 更新間隔 | ポーリング周期を秒単位で調整（省電力配慮） |
| スタートアップ | Windows起動時の自動常駐ON/OFF |

設定は `%APPDATA%\BatteryWatcher\config.json` に保存。右クリックメニューから設定画面（簡易フォーム）を開ける形。

## 06. 決定した進め方

- ワークスペース全体がバッテリーウォッチャーというテーマ専用なので、1個の巨大EPICで包括するのではなく、開発プロセスの区切り（調査→MVP→…）ごとに個別のEPICを立てていく方針
- BW-001は「調査」タスクとして完了。実装は次のMVP用EPICで進める
- MCP連携はスコープ外（今回は見送り）

### MVPで最初に作る骨格（次EPICの子タスク候補）

1. **プロジェクト作成**: .NET 8 WinForms、Native AOT向けにpublish設定を先に用意
2. **バッテリー値取得**: GetSystemPowerStatus呼び出し＋PowerModeChangedイベント配線
3. **アイコン動的描画**: GDI+で%数字を焼き込むビットマップ生成ロジック
4. **しきい値配色**: デフォルトの緑/黄/赤しきい値を実装
5. **右クリック設定画面**: 表示形式・しきい値・配色を変更できる最小限のフォーム
6. **スタートアップ登録**: 設定画面からON/OFFできるように
